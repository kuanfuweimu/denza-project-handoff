## 3. 启动方式与四种视图模式

- **一键启动**：双击 `start.bat`（或运行 `powershell -ExecutionPolicy Bypass -File start.ps1`），本地服务端口 `8789`。
- **主画面与 3D 模拟**：`http://localhost:8789/index.html`
- **控制台面板**：`http://localhost:8789/control.html`
- **4 种视图模式（按 `V` 键或 URL `?view=` 切换）**：
  - `?view=split`：左半屏上下同时监看「投影机 #1 双墙合投」与「投影机 #2 地面独投」，右半屏实时渲染「SketchUp 3D 现场空间双投影模拟（含中央悬吊方盒遮挡）」。
  - `?view=wall`：**投影机 #1 (`WALL_COMBINED`)** 全屏纯净输出（可直接送入墙面投影机或 Arena/TD）。
  - `?view=floor`：**投影机 #2 (`FLOOR_STAGE`)** 全屏纯净输出（可直接送入地面投影机或 Arena/TD）。
  - `?view=stage3d`：**SketchUp 3D 现场双投影模拟** 全屏预览（支持鼠标拖拽旋转视角、滚轮缩放）。
- **对位校准网格**：按 `G` 键叠加 1 米建筑网格、V 墙中缝轴线与地面 `R = 3.2m` 舞者圆环。
