# 投影交接：先确认机位与投射面

设备方最近询问：投影安装距离、映射面积，以便计算镜头比。以下是**可追溯的历史模型数据**，不是最终安装单。

## 场景一现有数值

来源：`quickstart/projection-simulation/out_C/plan_result.json`、`quickstart/projection-TD/td_assets/projectors.json`。原件在Release恢复的 `01_场景1_墙面双投影` 中。

| 项目 | 历史值 | 解释/限制 |
|---|---|---|
| 台数 | 双投影 | 旧模型方案，不代表设备供应已确认 |
| 模拟机位高度 | 4.5m | 模型Z-up坐标，需确认现场基准和镜头中心 |
| 平均投射距离 | 12.3m/台 | 模型采样的平均距离，非现场净距，也非所有面上的相同投距 |
| 单台在平均距离的完整成像宽度 | 12.7m | 用于初步镜头讨论，非整面展开宽度 |
| 历史镜头比 | 0.96 / 0.97 | 约1:1量级；不能直接指定订货型号 |
| 墙面展开宽×高 | 27.784×6m | 折面展开尺寸，不能当一台投影机的平面画幅 |
| 模型观众可见墙面面积 | 159.8㎡ | 不是棚面积；与27.784×6约166.704㎡的展开包络面积不是同一口径 |
| 历史覆盖/阴影 | 86.1% / 13.9% | 特定几何与采样的旧模拟，尚有遮挡，不是完整覆盖承诺 |
| 内容画布 | 7680×1656 | 展开UV内容输入 |
| 左/右输出 | 各3840×2400 | 旧TD输出设置，不等于当前4K16:9演示视频 |
| 观众预览 | 3840×2160 | 预览，不是双投影拼接交付规格 |

初算关系：投射比≈镜头到屏幕的投射距离÷完整成像宽度；12.3÷12.7≈0.969。异形、斜投、镜头偏移、裁切和遮挡需要回到3D几何及具体厂商镜头工具，不能只按总面积求一个比值。

## 坐标与左右：容易出错

原模拟 `sim.py` 用米、Z-up：L机位 `[22,15,4.5]`，R `[8,15,4.5]`。导出到TD的变换是 `(x,y,z) -> (x,z,-y)`。`export_td.py` 同时明确交换 L/R（观众侧命名）：TD L `[8,4.5,-15]`，TD R `[22,4.5,-15]`。不要直接混用两个JSON里的L/R；以真实机位编号和现场朝向重新标定。

## 设备型号与亮度：历史脚本有不同假设

`projectors.json` 明写 Panasonic PT-RQ45K class **assumed**，不是已订设备。模拟 `sim.py` 则使用46200 lm，且像素估算列含5120×3200，不能等同TD的3840×2400输出或实际设备。

2026-11-12核对[Panasonic PT-RQ45K官方规格](https://docs.connect.panasonic.com/projector/products/rq45k/spec/)：当前页面列42000 lm、Quad Pixel Drive输出3840×2400，DLP像素为1920×1200×3。**旧46200 lm和5120×3200指标不应继续作为该型号定案依据。** 历史lux/nits估算亦不能直接承诺现场亮度；先确认设备、镜头、供电/模式、表面材质和实际灯光再重算。

厂商核验入口：[投射距离计算器](https://docs.connect.panasonic.com/projector/calculator/tdc/index.html)、[镜头选型表](https://docs.connect.panasonic.com/projector/optional_lens_guide/)。这里未替用户确定型号、镜头、台数或采购。

## 场景二：目前不能给确定投距/面积

用户定义为投影打吊顶。已有SKP吊顶仰视、方案第8/9页、效果参考；尚缺明确可投表面与最终几何。蓝色层叠装置/半透明幕和吊顶的对应尚未定，不要混为一物。

需要向制作/场地方拿到：

1. 最终吊顶可投面的宽×深、离地高度、厚度/分块、曲面或折面、材质颜色和透明度。
2. 镜头中心允许位置和高度、到各目标面的最短/最长光程、吊点/马道与遮挡区。
3. 正投/背投、几台、可用投影型号及镜头清单；是否需要融合/几何校正。
4. 舞者/车辆/摄影机动线、舞台灯光条件；需要多大安全余量由设备和场地方确认。
5. 内容画布、每路输出、fps、播放与同步方式。

拿到这些后再做逐面覆盖与遮挡计算，输出机位图、对应镜头范围及待验证项。不要把LED棚的顶屏18.24m直接用于此场景。

## 模型版本与验证边界

用户指定的新SKP在 `DENZA N/腾势空间结构.skp`；旧模拟保存了另一份 `计算与模拟/source.skp`，两份文件大小不同。必须比较几何/版本，不要默认为完全一致。

归档TD已将5个模型/图像依赖改为同目录td_assets，并校验重打包内容一致；`runtime_tested:false`。旧工程可能含SOP读取模型，这是旧档现状；新内容不按此例新增SOP。
