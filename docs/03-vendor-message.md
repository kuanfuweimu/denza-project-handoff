# 给设备方的沟通稿（待用户转发，未发送）

老师，我们目前分墙面双投影、吊顶投影和另外一个LED棚三个场景。

墙面双投影这边，现有旧模型方案可以先给您做镜头范围参考：两台，模型机位高度约4.5米；单台到目标面的平均投射距离约12.3米，对应完整成像宽约12.7米，镜头比约0.96–0.97。整面是折面墙，展开约27.8米宽、6米高，模型可见墙面约159.8平方米。这些是历史模型模拟值，还不是现场确定安装尺寸，也不是每台都投27.8米宽。

吊顶投影这边，还需要制作方明确最终投射面的宽深、离地高度、材质，以及可吊挂机位，暂时不能直接套用墙面的投距。LED棚属于另一套屏幕系统。

您方便先发一下可用投影机型号和镜头清单吗？我们把最新结构图、投射面尺寸和可用机位对齐后，再请您确认实际镜头范围、覆盖和安装条件。现在模型里还有遮挡，需要一起核查，不能按已经满覆盖处理。
