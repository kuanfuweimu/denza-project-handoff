| 屏幕 | 物理尺寸 | 像素 |

| 顶屏 | 18.24×18.24m | 7296×7296 |
| 墙屏 | 24×7.68m | 9600×3072 |
| 右移动屏 | 3.84×4.30m | 1536×1720 |
| 左移动屏 | 5.44×5.28m | 2176×2112 |

原图还标顶屏离地7.68m、黑棚马道离地12.8m。平面图标LED棚1200㎡、黑棚1100㎡——**棚面积不是投影映射面积**。

多层半透明屏尺寸图标有7000、5040、3360、5000mm等尺寸；它和最终三个场景的对应关系未确认，不能拿来默认计算吊顶或LED。
